## What's new in 0.8.0

**Work through a server**
- Projects can now live on an **Evelopment Games Designer Server** ([separate download](https://github.com/Evelynnsrepos/Evelopment-Games-Designer-Server)) that you or your team runs. The server keeps a copy of the project, so people can join and catch up even when nobody else is online.
- **Join project** now also takes a connect code from a server (it starts with `EGS1-`). Every person gets their own code from the server's admin page, and a code can be for editing or view only.
- **Move to server**: in Work together, open "Or work through a server", paste a connect code and the open project is copied to the server. People you shared with directly need their own connect code afterwards.
- The Work together window shows the server's name and who is online right now.
- A server can **offer plugins** its admin installed. The app asks before anything installs, shows the usual plugin warning for each one, and asks again when a plugin changes on the server.
- If a server uses its own (self-signed) certificate, the connect code carries its fingerprint, so the app only talks to that exact server.

**Spell check and the AI helper**
- Clicking an underlined word now opens a card that says what is wrong and offers up to 3 fixes, with Dismiss and Add to dictionary.
- The AI helper comes in two sizes in Settings: **Small** (1.1 GB, fast) and **Better** (2.5 GB, catches more).

**Help**
- The Help button no longer gets stuck. It opens a small Help window with how to report a problem, a **Report an issue** button that opens a GitHub issue, the repository, and the user guide (`F1` still opens the guide directly).
